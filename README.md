---

## ✨ Overview
Careerly is a modern, high‑performance web application designed to simplify career planning and growth.  
Instead of juggling multiple websites, Careerly centralizes everything you need:  
- Career roadmaps  
- Resume builder  
- Learning resources  
- Quizzes & assessments  
- Conversational chatbot  

A clutter‑free, guided experience that helps you move forward with clarity and confidence.

---

## 🛠 Tech Stack

| Layer      | Technology | Why It’s Used |
|------------|------------|---------------|
| **Frontend** | HTML, CSS, JavaScript, React.js | Structure, styling, interactivity, and reusable UI components |
| **Backend**  | Node.js, Express.js | Handles server logic, API requests, and routing |
| **Database** | MongoDB (NoSQL) | Flexible, scalable storage for user data, resources, and chat history |

---

## 📦 Core Modules
- **Dashboard** – Personalized recommendations & saved resources  
- **Career Roadmaps** – Structured paths (Software Developer, Data Scientist, UI/UX Designer, etc.)  
- **Resume Builder** – Interactive resume creation with templates  
- **Learning Resources** – Centralized tutorials & curated study materials  
- **Quiz & Assessment** – Knowledge testing & performance tracking  
- **Chatbot Integration** – Instant answers, guidance, and resource suggestions
